📋 Report Text — Copy for One-Pager

📄 How to copy text from downloaded PDF:
1. Open the downloaded PDF in Adobe Acrobat Reader or your browser.
2. Press Ctrl+A (Windows) or Cmd+A (Mac) to select all text, OR drag to select specific text.
3. Press Ctrl+C / Cmd+C to copy.
4. Paste anywhere with Ctrl+V / Cmd+V.
Note: If the PDF was created as an image scan, text may not be selectable. Use the "Copy Report Text" button above instead to copy all report text before downloading.
